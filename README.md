# Custom Object Detection using YOLOv8

## 📌 Overview
This project implements a custom object detection model using YOLOv8 to detect vehicles in images.

## 🚀 Features
- Custom dataset training
- YOLO format annotation
- Real-time object detection
- Bounding box visualization with confidence scores

## 🛠️ Tech Stack
- Python
- OpenCV
- YOLOv8 (Ultralytics)
- NumPy, Pandas

## 📊 Results
- Successfully detected cars with high accuracy
- Achieved good precision and mAP scores
